# Generated audio classes

These data-only classes are generated from reviewed Carbon schema metadata by
the source-generation tooling owned by `@carbonenginejs/tools-core`. They ship
as runtime source because schema registration and Black/RED hydration require
their class identities at runtime.

The generator banner in each class is the overwrite boundary. Behavior-bearing
classes do not belong here: promote them into the maintained audio graph before
adding behavior, and keep their generated replacement disabled.
