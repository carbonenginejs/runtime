# libsquish 1.15 reference blocks

These synthetic RGBA inputs and expected compressed blocks were generated by
unmodified libsquish 1.15, not by the JavaScript port.

Archive: https://downloads.sourceforge.net/project/libsquish/libsquish-1.15.tgz
SHA-256: `628796eeba608866183a61d080d46967c9dda6723bc0a3ec52324c85d2147269`.
Scalar build: MSVC 14.50.35717 x64, `/O2 /EHsc /fp:precise`,
`SQUISH_USE_SSE=0`, `SQUISH_USE_ALTIVEC=0`.

For each entry of `libsquish-1.15.json`, decode `rgba` as 64 bytes and call
`squish::CompressMasked(rgba, mask, output, format | quality)` with each of
`kDxt1`, `kDxt3`, `kDxt5`, `kBc4`, `kBc5`, crossed with
`kColourIterativeClusterFit`, `kColourClusterFit`, `kColourRangeFit`.
Do not request `kSourceBGRA` or alpha weighting; the metric is the default.
Record 8 bytes for DXT1/BC4 and 16 for the others. The JSON's blocks are
indexed in that format/quality order: 154 inputs, 2,310 exact outputs.
Inputs include solid colours, transparent and threshold alpha, masked edge
blocks and deterministic random blocks. See `format-notices/dds/NOTICE`
for Simon Brown's and Ignacio Castano's MIT notices.

Carbon's RT enum aliases are tested against this same implementation;
no id Software encoder code or reference implementation ships here.
